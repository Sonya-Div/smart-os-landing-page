## 🌍 باللغة العربية

موقع ويب تفاعلي من صفحة واحدة يعرض أشهر أنظمة التشغيل (Apple, Windows, Android) بتصميم عصري وأنيق (تأثير زجاجي Glassmorphism). تم تطوير هذا المشروع للتركيز على مهارات البرمجة النظيفة (Clean Code) والتعامل الديناميكي مع واجهة المستخدم باستخدام الجافاسكريبت.

### ✨ الميزات الاحترافية في المشروع:
* **الوضع الداكن الذكي (Smart Dark Mode):** إمكانية التبديل بسلاسة بين الوضعين الفاتح والداكن مع تغيير الأيقونات والألوان ديناميكياً.
* **حفظ خيارات المستخدم (Local Storage):** يتذكر الموقع وضع الثيم المفضّل للمستخدم حتى بعد تحديث الصفحة أو إغلاق المتصفح.
* **نظام إعجابات متكامل (Like/Unlike System):** يمكن للمستخدم وضع إعجاب أو إزالته، حيث تمتلئ الأيقونة وتفرغ مع زيادة ونقصان العداد الحقيقي.
* **كود نظيف ومختصر (Clean Code - DRY):** تم دمج منطق الـ Likes بالكامل باستخدام **دالة موحدة ذكية (Reusable Function)** مع معاملات نائبة (Parameters) لتجنب التكرار.
* **تصميم متجاوب (Responsive Design):** الموقع متوافق تماماً مع شاشات الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة.

### 🛠️ التقنيات المستخدمة:
* **HTML5:** لبناء الهيكل وتوزيع العناصر.
* **CSS3:** للتنسيق الحركي، التدرجات اللونية (Gradients)، تأثير الـ Hover، والـ Media Queries.
* **JavaScript (ES6+):** لبرمجة المنطق، التعامل مع الـ DOM، والـ Local Storage.
* **Font Awesome:** لجلب الأيقونات التفاعلية.

## 🇬🇧 English Version

An interactive, single-page website displaying the most popular operating systems (Apple, Windows, Android) with a modern and elegant Glassmorphism design. This project was developed to showcase clean coding practices (DRY principle) and dynamic UI manipulation using JavaScript.

### ✨ Advanced Features:
* **Smart Dark Mode:** Seamless switching between light and dark modes with dynamic icon and color updates.
* **Persistent Settings (Local Storage):** The website automatically remembers the user's preferred theme mode even after a page refresh or closing the browser.
* **Interactive Like/Unlike System:** Users can toggle likes; the heart icon dynamically changes between regular (empty) and solid (filled) while updating the live counter.
* **Clean Code & Reusable Functions (DRY):** Optimized the like mechanism by writing a single **Reusable Function with parameters**, avoiding code repetition.
* **Fully Responsive:** Completely optimized for smartphones, tablets, and desktop views.

### 🛠️ Technologies Used:
* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom layouts, gradient backgrounds, hover effects, and media queries.
* **JavaScript (ES6+):** DOM manipulation, event listeners, functions with parameters, and Local Storage.
* **Font Awesome:** Scalable vector icons.
